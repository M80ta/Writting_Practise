# 中文注音練習紙

## 開啟與切換

直接開啟 [`javascript/chinese.html`](../javascript/chinese.html)，會進入 `index.html?mode=chinese` 的中文預設模式。也能在既有介面選擇「中文注音」範本，切換至田字格、中文範字及附注音標楷字型。

中文入口與一般入口使用不同的自動儲存 key，避免中文入口第一次開啟時被既有英文編排取代。在同一入口內切換範本會取代目前內容與範本版面，請先下載 JSON 保留需要的編排。

中文新編排預設為 **A4 直向、四邊各 8mm、每頁 13 行、每行 8 格、每格配置 24 × 17mm、行距 2mm**。每格配置包含國字與注音區，不另加水平間距；實際國字方框會依字級與配置尺寸縮放。已有自動儲存的編排會保留原版面，重新套用「中文注音」範本才會切換到新預設。

## 編輯國字與格型

左側輸入每行國字，使用**逐格國字**排列。紙張設定提供田字格、米字格與方格，右側預留注音區；可調整每頁行數、每行格數、格寬／格高、行距與字級。中文格型只使用逐格排列；切換中文格型時，現有行也會改成逐格排列。

田字格的國字方框依該行字級與格寬高限制計算，中文字型的漢字與注音總寬為 1.5 em。格子較窄或較矮時會限制實際字級。內容超出每行格數會提示，不會自行流到下一行；可手動新增行。

## 字型與多音字

| 選項 | 紙上的字形 |
| --- | --- |
| 字嗨注音標楷 · 附注音 | 國字加右側注音，使用字型預設或你選擇的讀音 |
| 字嗨標楷 · 純國字 | 使用同一字型的無注音異體，保留原本儲存的讀音選擇 |

調整多音字：

1. 點紙上的一格，輸入單一國字，例如「行」或「重」。
2. 查看「選擇注音讀音」的圖卡。每張圖卡直接以字型顯示該讀音。
3. 點選適合詞義的讀音，再按「套用文字」。也可選擇這一格不顯示注音。
4. 列印、JSON 儲存及重新載入都會保留選擇。切換成純國字後再切回附注音，也會保留原選擇。

系統使用 Unicode IVS 選擇讀音，將國字與讀音標記視為同一個格子。它**不會依詞句自動判斷多音字、變調或兒化**；請依教材與詞義選擇。未在字型注音字集內的國字會提示，可能只顯示國字或替代字形。

中文模式保留實線、虛線輪廓描字、淡字與空白練習格，以及逐行新增／複製／排序、格子文字覆寫、紙張分頁與 PDF 列印。

## 字型載入與列印

中文注音字型約 **17.1 MB**，隨網站提供，不需要另外安裝。英文入口未使用中文字型時，不會要求載入這個字型檔。第一次進入中文模式請等字型載入完成；以本機檔案開啟若被瀏覽器限制，請改用 `node scripts/preview.cjs` 或部署後的網站網址。

字型載入失敗時，程式會顯示提示並暫停列印，避免以沒有注音的替代字型產生範字。字型成功載入後，預覽與列印使用同一份 SVG。實際瀏覽器與印表機仍應先預覽並試印。

## 維護與驗證

`node --test` 包含中文分頁、格型、IVS 不占第二格、讀音與純國字切換、儲存還原、字型失敗阻擋列印，以及原始字型 SHA-256 測試。另以 Pillow / HarfBuzz 實際產生字形樣張，確認預設讀音、其他讀音及無注音字形不同；這不取代瀏覽器畫面或實體列印驗證。

更新字型後可在具備 Python 與 fontTools 的維護環境執行 `python javascript/scripts/generate-zhuyin-data.py` 重建 cmap metadata，並重新核對上游版本、授權、雜湊與測試。使用網站不需要 Python。
